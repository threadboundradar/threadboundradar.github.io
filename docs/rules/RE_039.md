# RE_039 · Early combined warning: draw calls + GPU time

| Category | Severity | Fires while | Target |
|---|---|---|---|
| Rendering | Low | Playing | 60 FPS only |

## What it means

Draw calls and GPU time are both elevated at the same time, though the frame still meets budget. The combination of both signals anticipates that RE_001 could trigger soon if the scene keeps growing.

## When it fires

All of these are true at the same time, averaged over one second:

| Measurement | Looks for | What it is |
|---|---|---|
| Draw calls | High | Commands sent to the GPU this frame |
| GPU time | High | Time the GPU spends on this frame |
| GPU bound | Yes | The GPU, not the game thread, is what limits the frame |
| Frame time | Low | Total time to produce this frame |

This rule only applies to a 60 FPS target. The plugin hides it entirely when the project's target frame rate is set to 30 FPS, where the same measurement can still fit the budget.

## Why it happens

Neither measurement alone is severe yet, but rising together is a stronger signal than either alone: they're the same two conditions RE_001 checks, just below its thresholds.

## How to fix it

1. **Apply instancing preventively** before reaching the critical threshold in RE_001.
2. **Monitor this combination across sessions** using the session history.

## How to confirm the fix

Watch **Draw Calls** and **GPU Time** in Live Metrics. Once either falls back under its threshold, the rule stops firing and its row in Diagnostics is no longer marked active.
